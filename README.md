#  Dataset

## 📌 Overview
This repository contains sample  datasets for data analytics and data engineering projects. The datasets are organized by file format to support data ingestion, transformation, validation, and analysis.

## 📂 Repository Structure

```text
Loan-Portfolio-Dataset/
│
├── csv_data/
│   ├── Loan_Details.csv
│   ├── Repayment_Details.csv
│   ├── Credit_Bureau.csv
│   └── Loan_Schedule.csv
│
├── json_data/
│   └── loan_data.json
│
├── excel_data/
│   └── loan_data.xlsx
│
└── README.md
```

## 📊 Dataset Description

| Dataset | Description |
|---|---|
| Loan Details | Loan and customer information |
| Repayment Details | Repayment transaction records |
| Credit Bureau | Credit scores and credit history |
| Loan Schedule | Scheduled loan installments |
